## A. Mục tiêu / ngoài phạm vi / mặc định

**Có:**
- Loại nhiệm vụ mới `kind: "louvre"`: phòng 3D kín dưới hòm Louvre, **23 tác phẩm quanh tường** (5 độc bản Louvre + 18 bẫy; ≈ 15 tranh treo tường + 8 tượng trên bệ sát tường), nút đỏ / xanh dưới mỗi tác phẩm (F), nút chốt giữa phòng (F), máy chủ tự chấm (bộ 5 id chỉ ở máy chủ), sai → phạt `retryLockMinutes` (3) đếm ngược (lựa chọn giữ nguyên, bấm / bỏ được, không chốt được), đúng = đủ 5 và không thừa → bước xong, mật thư kế ngay.
- Gợi ý riêng đội phút 40 "Đáp án bao gồm 5 tác phẩm" và phút 70 "Đúng x/5" **cập nhật sống theo lựa chọn hiện tại** (x = |picks ∩ đáp án| tính thuần khi đọc thẻ, chỉ gửi cho chính đội); mốc tính từ `task_started_at` (= lúc mở hòm Lộ trình trước, không phải lúc vào phòng), cấu hình trong chặng. Tin công khai tới mọi đội (feed góc dưới): "Đội X trả lời sai và bị phạt 3 phút"; sau phút 70 của đội đó, mỗi lần chốt công khai thêm "đúng x/5".
- Vào phòng bằng F ở hòm Louvre (hòm của Lộ trình ngay trước, đã mở), ra bằng F ở cửa; cửa nằm **thẳng đứng dưới hòm** nên vào / ra chỉ đổi y (không teleport theo x,z, không gửi `respawn`). Người chơi trong phòng thấy nhân vật nhau (ticks sẵn có); đèn / nút chỉ là mesh cục bộ vẽ từ thẻ của chính đội.
- Ảnh / mô hình 23 tác phẩm = **tài sản tĩnh** `client/public/art/art-NN.webp` (tên trung tính, metadata xóa, thứ tự xáo, commit sau khi người dùng duyệt §M); không R2, không Host tải lên. Bí mật duy nhất = 5 id trong `task.answers` ở máy chủ. Tên tác phẩm không hiện ở đâu phía client (kể cả `credits.json`: `leg:check` quét).
- **Ghi nguồn sau đích** (§17.20): ghi công chi tiết (tên tác phẩm, tác giả, ảnh, giấy phép, nguồn) nằm trong chặng (`artworks[].credit`, server-only); bảng "Ghi nguồn" trong cuộc đua chỉ mở khi đội đã về đích hoặc cuộc đua kết thúc – client xin `{op:'credits'}`, máy chủ trả danh sách hoặc notice "Mở sau khi về đích". Offline (`?offline=1`) bảng mở như cũ với `credits.json` tĩnh.
- **Tối đa 5 lựa chọn từ phút 40** (§17.19 (c)): bật nút khi đã có ≥ 5 đèn và `now ≥ hintAt[0]` → từ chối (notice `pickLimit` "Chỉ được chọn tối đa 5 tác phẩm"); bỏ chọn luôn được; trước phút 40 không giới hạn (đèn > 5 bật từ trước mốc giữ nguyên tới khi đội tự bỏ).
- Host: ma trận hiện số lần chốt sai, số đang chọn, mốc gợi ý đã tới, x/5 sống sau mốc 70; lịch sử từng lần chốt (số id + đúng x/5) khi rê chuột. Không cần Host duyệt.
- Công cụ: `leg:check` luật mới (kể cả kiểm tệp tĩnh + thứ tự đáp án), bot `sim`, test thuần + harness, preset chụp phòng với placeholder.

**Mặc định đã áp dụng (chờ xác nhận, §K):** (1) Đúng = chọn **đúng 5 và không thừa** (6 món có đủ 5 đúng vẫn sai). (2) Gợi ý 40 chỉ hiện trên thẻ + toast riêng đội; không công khai. (3) Chốt không có hộp xác nhận; chốt với 0 lựa chọn bị client chặn tại chỗ (máy chủ vẫn chấm sai nếu client sửa). (4) Số lần chốt không giới hạn. (5) Bị phạt 3 phút: đồng hồ đua chạy, cả khi Host tạm dừng (D9 Phase 7). (6) Ra khỏi phòng bất kỳ lúc nào (F ở cửa), lựa chọn giữ; F5 trong phòng → vào lại đúng chỗ trong phòng (`welcome.pose.y`); F5 sau khi đã chốt đúng mà chưa ra → đứng trên sân Louvre (tự "ra"). (7) Thử thách louvre **không có `task.location`**: phòng nằm tại hòm vừa mở (bước trước phải là `route_info`). (8) `verification` của louvre bắt buộc `auto` (khác → `leg:check` error; máy chủ còn chặn op `answer` cho bước louvre). (9) Tượng = ảnh trên bệ (placeholder tới khi có GLB). (10) Khóa 3 phút của louvre dùng lại `task.retryLockMinutes ?? penalties.retryLockMinutes`. (11) Feed công khai ở **góc dưới bên trái** (trên minimap, kiểu chat GTA), vị trí cấu hình `feed.corner` trong `config.ts`. (12) Giấy phép tài nguyên theo SPEC §17.19 (a) / §17.20: PD / PD-Art / CC0 / CC-BY / **CC-BY-SA / CC-BY-NC / CC-BY-NC-SA** (phi thương mại, ghi nguồn đầy đủ); **cấm ND**, "chỉ dùng cá nhân", không rõ giấy phép. (13) Hệ quả của x sống + tối đa 5 đèn sau phút 40: sau phút 70 đội dò đáp án bằng cách **đổi từng đèn** (tắt một, bật một, đọc x đổi ±1) – vẫn ≤ ≈ 23 lần đổi, không bị phạt (phạt chỉ ở chốt); khó hơn bật / tắt tự do nhưng vẫn khả thi – chấp nhận theo SPEC; nút giảm rẻ nhất là `hints.correctAtMinutes` muộn hơn. (14) Cảnh báo kẹt 45 phút của Host (`stuckAlerts`) vẫn nổ cho đội ở phòng Louvre song song với gợi ý 40 / 70 – cố ý (Host vẫn cần biết). (15) Ghi nguồn sau đích: nút "Ghi nguồn" trong menu khi đang đua và chưa về đích → bấm được nhưng máy chủ trả notice "Mở sau khi về đích" (không ẩn nút, một đường mã); đội về đích / cuộc đua `finished` → bảng đầy đủ (tĩnh + phòng Louvre).

## B. Schema chặng + `leg:check` + tương thích ngược

`shared/src/leg/schema.ts` (mọi trường mới tùy chọn → file Phase 7/8 vẫn nạp):
```ts
TASK_KINDS += 'louvre'
const artId = z.string().regex(/^[A-Za-z0-9_-]{1,16}$/);
const artFile = z.string().regex(/^art-\d{2}\.(webp|glb)$/);             // tệp tĩnh client/public/art/<tên>; .glb = tượng có bản quét 3D hợp lệ
const artwork = z.strictObject({
  id: artId,
  type: z.enum(['painting', 'sculpture']).default('painting'),   // khung treo tường / bệ (ảnh đứng)
  image: z.union([artFile, z.literal('')]).default(''),           // '' = chưa có → placeholder đánh số
  note: text().default(''),                                       // CHỈ Host / người soạn (nơi thật, ghi chú); không bao giờ xuống client
  credit: z.strictObject({                                        // ghi nguồn (§17.20): server-only, gửi cho đội ĐÃ VỀ ĐÍCH qua op 'credits'
    title: text(),                                                // tên tác phẩm (bắt buộc khi image ≠ '': luật rò quét token của title)
    artist: text().default(''),                                   // tác giả tác phẩm
    photo: text().default(''),                                    // tác giả ảnh / mô hình
    license: z.enum(['PD', 'PD-Art', 'CC0', 'CC-BY', 'CC-BY-SA', 'CC-BY-NC', 'CC-BY-NC-SA', 'MIT']),   // §17.19 (a) / §17.20: không ND, không "cá nhân", không "không rõ"
    source: z.string().url().or(z.literal('')).default(''),       // URL nguồn (chỉ xuống client sau đích)
  }).optional(),
});
taskSchema += {
  louvre: z.strictObject({
    artworks: z.array(artwork).length(23),   // 5 thật + 18 bẫy (SPEC §17.19); tỉ lệ tranh / tượng không ép (≈ 15 / 8)
    hints: z.strictObject({ countAtMinutes: z.number().positive().default(40), correctAtMinutes: z.number().positive().default(70) }).prefault({}),
  }).optional(),
}
// Bộ 5 đáp án = task.answers (đã có, server-only): mỗi phần tử là một artwork.id, đúng 5, không trùng.
```
Bố cục phòng (kích thước, màu, bệ, khoảng cách nút…) **không** nằm trong chặng: `client/src/config.ts` khối `louvreRoom` (§F). Hướng phòng = `destination.yawDeg` của hòm bước trước. Thứ tự quanh tường = thứ tự `artworks[]` trong chặng (người soạn xáo; `leg:check` cảnh báo nếu 5 đáp án đứng liền nhau).

Nhãn `check.ts FIELD`: `louvre: 'phòng Louvre'`, `artworks: 'tác phẩm'`, `image: 'hình tác phẩm'`, `note: 'ghi chú (chỉ Host)'`, `credit: 'ghi nguồn'`, `title: 'tên tác phẩm'`, `license: 'giấy phép'`, `hints: 'mốc gợi ý'`, `countAtMinutes: 'phút gợi ý số lượng'`, `correctAtMinutes: 'phút gợi ý số đúng'`.

**Luật mới trong `checkLeg`** (server + CLI) cho bước `challenge` có `task.kind === 'louvre'`:
1. `task.louvre` thiếu → **error** "kiểu louvre cần khối `louvre.artworks` (23 tác phẩm)". `kind !== 'louvre'` mà có `louvre` → warning (bị bỏ qua).
2. `artworks` đúng 23 (zod); `type` toàn một loại → warning "nên ≈ 15 tranh + 8 tượng"; `id` trùng → error; `answers` đúng 5, trùng → error, id không có trong `artworks` → error (ghi id nào).
3. `image`: '' → **blank** "hình tác phẩm <id> chưa có (sẽ hiện ô đánh số)"; không khớp `art-NN.webp|glb` → error (zod); `.glb` với `type: 'painting'` → error; hai tác phẩm cùng tệp → warning. **CLI** (có hệ tệp): `client/public/art/<tên>` không tồn tại → **blank** "chưa có tệp, hiện ô đánh số"; `.webp` > 300 KB / `.glb` > 1 MB → warning. Giữ luật "tên hình chứa token ≥ 4 ký tự của `note`" → warning (tên `art-NN` không bao giờ vi phạm; chặn người soạn đổi tên).
4. Lộ đáp án: token của `credit.title` + `note` của **5 tác phẩm đúng** lọt vào `description`, `title`, `teaser`, mật thư bước ≤ i → warning (quét thứ tự như D2 luật 2); id tác phẩm (`answers`) không quét (chuỗi ngắn, trung tính). `image ≠ ''` mà thiếu `credit` → **warning** "thiếu ghi nguồn (tên, giấy phép) – bảng Ghi nguồn sau đích sẽ trống"; `credit.license` ngoài danh sách (vd. `CC-BY-ND`, `personal`, rỗng) → **error** (zod) "giấy phép không được phép (§17.20: cấm ND / chỉ cá nhân / không rõ)".
5. **Thứ tự gợi ý đáp án** (mới): 5 `answers` là 5 mục liền nhau trong `artworks` (kể cả vòng qua cuối → đầu) **hoặc** là 5 mục đầu / 5 mục cuối → warning "thứ tự trong phòng gợi ý đáp án; xáo lại `artworks`".
6. `task.location != null` → error "phòng Louvre nằm tại hòm vừa mở; bỏ `location`". Bước trước không phải `route_info` → error "trước thử thách louvre phải là một Lộ trình có hòm". `teaser` khác '' → warning "mốc gợi ý tính từ lúc mở hòm Lộ trình trước, không phải lúc bấm Nhận thử thách". Hai bước louvre cùng hòm (cùng vùng) → warning "hai phòng chồng nhau".
7. `verification !== 'auto'` → **error** "louvre do máy chủ tự chấm (`verification: 'auto'`)"; `referenceAnswers` → warning bị bỏ qua.
8. `hints.countAtMinutes >= correctAtMinutes` → error. `retryLockMinutes` < 1 → warning (như D2 luật 8).
9. Quét static (CLI `scanLeaks`): `secretStrings` thêm `credit.title` + `credit.artist` + `note` của mọi tác phẩm (bắt cả `client/public/credits.json` và `client/public/art/*` – quét bytes nhị phân của 23 tệp với token ≥ 4 ký tự); `answerStrings` thêm 5 id (chỉ khi dài ≥ 12, tức hầu như không).

CLI (`scripts/leg-check.ts`): in bảng 23 tác phẩm (id, loại, tệp, tệp có tồn tại?, giấy phép, có `credit`?) + đếm tranh / tượng, nhắc "23 tệp tĩnh trong `client/public/art/`, không cần tải lên trang Host". `mediaReport` / `r2Names` **không** gộp ảnh tác phẩm (không phải R2).

Tương thích: file cũ không có `louvre` → không đổi gì; `TASK_KINDS` thêm một giá trị; `LEG_FORMAT.md` §7.1 thêm kiểu `louvre` + §7.5 mới.

## C. Giao thức (`PROTOCOL_VERSION = 4`, hình dạng `ClueCard` / `Welcome` đổi)

```ts

// isClientMessage: art ≤ 16 ký tự theo artId; on boolean; view / credits không trường (codec.ts:108 thêm 'view' | 'credits' cạnh 'book').
// xuống

  room: { x: number; z: number; r: number; yaw: number /* rad */ };  // = vùng của bước (hòm vừa mở): client đã có tọa độ này

  hintCount: number | null;                // 5 khi now ≥ hintAt[0], else null (không gửi trước giờ)

interface CreditItem { file: string /* art-NN.webp */; title: string; artist: string; photo: string; license: string; source: string }

TaskView += { louvre?: LouvreView }        // chỉ kind louvre, chỉ khi status ≠ teaser
AnswerView += { correct?: number }         // số đúng của lần chốt, CHỈ khi rec.at ≥ hintAt[1] (trước mốc chỉ 'wrong'); text = "k tác phẩm" (chuỗi do server tạo)
// Feed công khai (tới MỌI socket đội + Host), không ghi dòng riêng (sự kiện `louvre.lock` đã ghi):
{ t:'feed'; at: number; slot: number; ok: boolean; minutes?: number /* phạt, khi !ok */; n?: number /* đúng n/5, chỉ khi đội đã qua mốc 70 */; of?: number /* 5 */ }
// MỘT tin mỗi lần chốt: sai trước 70 → "Đội X trả lời sai và bị phạt 3 phút"; sai sau 70 → "… · đúng 2/5"; đúng sau 70 → "Đội X đúng 5/5"; đúng trước 70 → không tin (feed chỉ về sai + x/5).
Welcome += { feed: FeedMessage[] }         // NET.feedKept (20) tin mới nhất theo thứ tự thời gian tăng, dựng từ bảng events khi DO thức dậy
ServerNotice += 'lockWrong' | 'pickLimit' /* "Chỉ được chọn tối đa 5 tác phẩm" */ | 'creditsLocked' /* "Mở sau khi về đích" */   // đúng → 'clueNew' sẵn có
HostState.leg.steps[] += { louvre?: { hints: [number, number] } }; StepProgressView += { picks: string[]; hintCorrect: number | null /* sống */; answers[].correct?: number }
```
